## Motion Components

This site uses selected web components from [Motion Components](https://www.motion-components.dev/), version 0.5.0, for reveal, stagger, press, text-mask, spotlight, and scroll-progress interactions.

Motion Components is distributed under the MIT License. Copyright © tgomilar and contributors. The complete package license is included with the installed dependency at `node_modules/motion-components/LICENSE`.

The components were selected for framework independence, restrained physics-based motion, and built-in reduced-motion behavior. Avarent's layouts, copy, visual system, and product diagrams are original to this project.

## Design references

The redesign studies public pages from Modern Treasury and Vanta for high-level patterns such as technical hierarchy, proof placement, committed color surfaces, and restrained product-led motion. No proprietary source code, brand assets, customer marks, or pixel-identical layouts were copied.

## User-supplied Silk shader

The hero uses the “Silk” WebGL shader generated by the 21st.dev Shader Builder and supplied directly with the project request. Its React lifecycle wrapper was adapted to this site's framework-free runtime. The shader remains dependency-free and pauses off-screen and when reduced motion is requested.
